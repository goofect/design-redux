# Reduction

The plugin's visible navigation has one job per screen: the library lists
folders, a folder lists notes, and a note displays its complete text in
Obsidian. The 3D graph remains a separate view.

The former grid, shelf, outline and table browsers, search and details panel,
separate tree map, note header, note-page controls, properties panel and bottom
strip are retired. Old map, outline and properties-panel workspace tabs close
through compatibility views. Removed screen settings and saved views are kept
in plugin data; note files are not rewritten. Existing page markers remain in
notes and all their text is shown.

The file index and Obsidian's file and workspace APIs remain the shared
foundation. Keep a visible control only when it is needed to navigate, read or
edit. Keep selection and keyboard focus legible in both light and dark themes.
